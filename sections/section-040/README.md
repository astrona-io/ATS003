# Section 040: Time & Domain Name Services (NTP & DNS)

Infrastructure timing and naming services underpin all networked transaction logs and node communication. This portal coordinates the conceptual reading, guided training, and unguided challenge sandboxes for NTP client configuration, NTP server-mode strata propagation, and DNS verification with dig.

---

## What You Will Master

By completing this section, you will acquire three core capabilities:
*   **NTP Client Stepping**: Configure Chrony clients, edit query poll intervals, and enforce startup step corrections.
*   **NTP Server Stratum Policies**: Serve time safely to local subnets using the "allow" directive and check server stats.
*   **DNS Resolver Verification**: Perform deep DNS zone queries, target records (MX, NS, PTR), and strip output meta with "+short".
