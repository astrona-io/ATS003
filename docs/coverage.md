# Curriculum and lab coverage

The main course has 26 labs. Another 4 exercises remain available outside the ordered course in `practice.yaml`; their paths and runtime IDs remain valid. CI runs all 30 labs and 24 playgrounds, including optional and legacy exercises.

Each lab starts independently, fails an intended unfinished-state check, runs its reference solution as `student`, and passes every grader. Negative cases restore the solution and recheck all graders. A reboot is included where listed. Every playground has a smoke check. Use the latest PR check and uploaded logs for actual runtime results.
